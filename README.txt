GLITCHVERSE - Unity (2D)

SETUP
1. Create a new 2D project in Unity Hub (2019+ or Unity 6).
2. Copy Assets/Scripts/GlitchVerse.cs into your project's Assets folder (any subfolder).
3. Open any scene (empty is fine) and press Play.

The script builds the camera, levels, player, platforms and UI by itself.
No tags, layers, prefabs or Canvas needed.

CONTROLS
A/D move | Space jump | E flip gravity | Q freeze time | R switch dimension
Backspace restart | Enter start

LEVEL FORMAT (edit MakeLevels() in GlitchVerse.cs)
# wall   ^ spike   o shard   P player start   E exit   A/B dimension blocks
